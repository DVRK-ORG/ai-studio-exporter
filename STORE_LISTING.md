## Detailed Description

🔥 AI Studio Exporter | Obsidian Edition — The ultimate export tool for Google AI Studio conversations.

✨ FEATURES:
• Multi-Format Export — Save conversations as Markdown (.md), PDF (.pdf), JSON (.json), or Plain Text (.txt)
• Reasoning Extraction — Toggle inclusion of AI "Thinking" blocks for complete conversation context
• Obsidian-Optimized — Markdown output follows Obsidian linking and formatting conventions
• 100% Client-Side — All processing happens in your browser. Zero data leaves your machine
• Premium UI — Ultra-dark carbon fiber theme with glassmorphism overlays
• Smart Connection Recovery — Built-in monitors detect and fix communication gaps automatically

🎯 BUILT FOR:
• Obsidian PKM users who export AI conversations into their knowledge base
• Developers who need structured JSON exports for analysis
• Researchers preserving AI reasoning chains and thinking processes
• Anyone who wants beautiful, formatted exports of their AI Studio chats

🔒 PRIVACY FIRST:
No data collection. No analytics. No external servers. Everything runs locally in your browser.

⚡ HOW TO USE:

1. Open any conversation on Google AI Studio
2. Click the extension icon in your toolbar
3. Toggle "Include Reasoning" if you want thinking blocks
4. Choose your export format — done!

Built with React 18, TypeScript, and Vite. Open source on GitHub.

## Privacy Practices

- Single Purpose: Export Google AI Studio conversations to various file formats
- Permission Justification:
  - activeTab: Read conversation content from the current AI Studio tab
  - scripting: Inject content script to extract chat messages
  - downloads: Save exported files to the user's computer
  - host_permissions (aistudio.google.com): Required to access AI Studio page content
- Data Usage: No data collected, stored, or transmitted. All processing is local.
- Remote Code: No remote code execution.
